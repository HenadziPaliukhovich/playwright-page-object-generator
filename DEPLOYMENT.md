## How to Run Locally

### Prerequisites
- Node.js 18+
- npm

### Installation
```bash
git clone https://github.com/HenadziPaliukhovich/playwright-page-object-generator.git
cd playwright-page-object-generator
npm install
npm run dev
```

### Access Application
- Frontend: http://localhost:5173
- Backend API: http://localhost:3001

## What Users Will See

### Home Page
- ✅ Clean two-panel layout
- ✅ Input panel on left (HTML, class name, language selection)
- ✅ Output panel on right (generated code)
- ✅ Multiple tabs (Page Object | Test File | Setup Guide)

### Features Available
1. **Paste HTML** - Directly into textarea
2. **Fetch from URL** - Load HTML from any website
3. **Select Language** - TypeScript, Python, or JavaScript
4. **Generate** - Click to generate code
5. **View Output** - See generated Page Object class
6. **View Tests** - Example test file for selected language
7. **View Setup** - Complete project scaffolding guide
8. **Copy Code** - One-click copy to clipboard
9. **Download** - Download generated file
10. **Test Locators** - Validate against real websites
